# YESCADA Backend

REST API сервер системы мониторинга зернохранилищ. Написан на Python/Flask.

## Стек

- Python 3.12, Flask >= 3.0
- SQLite (WAL mode)
- JWT аутентификация (access + refresh токены, HS256)
- Pydantic схемы валидации
- Flask-CORS для кросс-доменных запросов

## Быстрый старт

```bash
pip install -r requirements.txt
```

### Создание администратора

При первом запуске необходимо создать учётную запись администратора.
Не используйте `admin/admin` — это небезопасно для production.

**Вариант 1 — переменные окружения (рекомендуется для Docker/CI):**

```bash
ADMIN_USERNAME=admin ADMIN_PASSWORD=your-strong-password python run.py
```

Администратор создаётся автоматически при старте, если пользователей ещё нет.

**Вариант 2 — CLI-команда (для ручной установки):**

```bash
flask create-admin
```

Команда интерактивно запросит имя пользователя и пароль.

**Вариант 3 — Python API (для скриптов):**

```python
from app.db import seed_admin
seed_admin("admin", "my-strong-password")
```

`seed_admin()` создаёт администратора только если в БД нет ни одного пользователя.

## API Endpoints

### Auth
| Метод | Путь | Доступ | Описание |
|-------|------|--------|----------|
| POST | `/api/auth/login` | Публичный | Вход, возвращает access + refresh JWT |
| POST | `/api/auth/refresh` | Публичный | Ротация refresh токена |
| GET | `/api/auth/me` | Пользователь | Профиль текущего пользователя |
| PUT | `/api/auth/profile` | Пользователь | Смена имени/пароля |

### Sensor data
| Метод | Путь | Доступ | Описание |
|-------|------|--------|----------|
| POST | `/api/sensor/data` | Устройство | Приём показаний от контроллера |
| GET | `/api/sensor/data` | Пользователь | Последние показания датчика |
| PUT | `/api/sensor/rename` | Пользователь | Переименовать расположение датчика |
| GET | `/api/device/info` | Пользователь | Список датчиков пользователя со статусом |

### Admin
| Метод | Путь | Доступ | Описание |
|-------|------|--------|----------|
| GET, POST | `/api/admin/users` | Админ | Список/создание пользователей |
| DELETE | `/api/admin/users/:id` | Админ | Удаление пользователя |
| PUT | `/api/admin/users/:id/reset-password` | Админ | Сброс пароля |
| PUT | `/api/admin/users/:id/controllers` | Админ | Назначение контроллеров |
| GET | `/api/admin/controllers` | Админ | Список контроллеров |
| GET | `/api/admin/audit` | Админ | Журнал аудита (пагинация) |

### Health
| Метод | Путь | Доступ | Описание |
|-------|------|--------|----------|
| GET | `/api/health` | Публичный | Health check |

## Конфигурация

### Переменные окружения

| Переменная | По умолчанию | Описание |
|------------|--------------|----------|
| `SECRET_KEY` | - | Секретный ключ JWT (обязательно) |
| `ADMIN_USERNAME` | - | Имя первого администратора |
| `ADMIN_PASSWORD` | - | Пароль первого администратора |
| `CORS_ORIGINS` | `http://localhost,...` | Разрешённые origins для CORS |
| `LOG_LEVEL` | `INFO` | Уровень логирования |
| `LOG_FILE` | - | Путь к файлу логов |
| `FLASK_DEBUG` | `0` | Режим отладки |

### Параметры JWT

| Параметр | Значение | Описание |
|----------|----------|----------|
| `ACCESS_TOKEN_EXPIRES_SEC` | 3600 | Время жизни access токена (1 час) |
| `REFRESH_TOKEN_EXPIRES_SEC` | 604800 | Время жизни refresh токена (7 дней) |
| `JWT_ISSUER` | `yescada-core` | Издатель токена |
| `JWT_AUDIENCE` | `yescada-api` | Аудитория токена |
| `JWT_CLOCK_SKEW_SEC` | 30 | Допуск на расхождение часов |

### Параметры данных

| Параметр | Значение | Описание |
|----------|----------|----------|
| `KEEP_COUNT_DEFAULT` | 1000 | Количество показаний на датчик |
| `TEMP_MIN` | -50.0 | Минимальная температура |
| `TEMP_MAX` | 150.0 | Максимальная температура |
| `MAX_BATCH_SIZE` | 500 | Максимальный размер пакета |
| `MAX_KEEP_COUNT` | 10000 | Максимальный размер буфера |
| `TIMESTAMP_WINDOW_HOURS` | 24 | Окно допустимых таймстампов |

### Параметры безопасности

| Параметр | Значение | Описание |
|----------|----------|----------|
| `MIN_PASSWORD_LENGTH` | 12 | Минимальная длина пароля |
| `REQUIRE_PASSWORD_COMPLEXITY` | True | Требовать сложный пароль |
| `SESSION_CLEANUP_AGE_SEC` | 2592000 | Время жизни сессии (30 дней) |

## База данных

6 таблиц: `controllers`, `sensors`, `readings`, `users`, `user_controllers`, `audit_log`.

### Таблицы

| Таблица | Описание |
|---------|----------|
| `controllers` | Контроллеры (MAC-адрес, описание) |
| `sensors` | Датчики (адрес, расположение, контроллер) |
| `readings` | Показания (температура, время, датчик) |
| `users` | Пользователи (логин, пароль, роль) |
| `user_controllers` | Связь пользователей с контроллерами |
| `audit_log` | Журнал аудита (действия пользователей) |

Автомиграция при запуске — таблицы создаются если не существуют.

## Архитектура

```
app/
├── __init__.py         # Создание Flask приложения
├── config.py           # Конфигурация
├── db.py               # Работа с БД
├── auth.py             # JWT аутентификация
├── errors.py           # Обработка ошибок
├── schemas.py          # Pydantic схемы
├── sensors.py          # Логика датчиков
├── audit.py            # Журнал аудита
├── device_auth.py      # Аутентификация устройств
└── routes/
    ├── auth_routes.py      # /api/auth/*
    ├── sensor_routes.py    # /api/sensor/*, /api/device/*
    ├── admin_routes.py     # /api/admin/*
    ├── health_routes.py    # /api/health
    └── setup_routes.py     # Настройка при первом запуске
```

## Безопасность

- `SECRET_KEY` обязателен для запуска
- В production необходимо установить `ADMIN_USERNAME` и `ADMIN_PASSWORD`
- Пароли хешируются с помощью Werkzeug
- JWT токены с истечением времени
- Аутентификация устройств через `X-Device-Key` заголовок
- Audit log для отслеживания действий
